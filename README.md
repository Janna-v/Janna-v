Sono una sviluppatrice junior con un percorso di formazione nello sviluppo web full stack e in Java. Cerco un'opportunità per contribuire a progetti concreti, consolidare le mie competenze e crescere attraverso il confronto con un team.

- **Strumenti:** Git, GitHub, npm, Composer, Maven, Gradle e Docker.
