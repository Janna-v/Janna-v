# Giovanna Virdò

**Junior Full Stack Developer**

Sono una sviluppatrice junior con un percorso di formazione nello sviluppo web full stack e in Java. Cerco un'opportunità per contribuire a progetti concreti, consolidare le mie competenze e crescere attraverso il confronto con un team.

Ho realizzato applicazioni con frontend React, API Node.js/Express e Python e applicazioni web con Laravel e Spring Boot. Questi repository raccolgono esercitazioni, prototipi e progetti formativi: nei singoli README descrivo le funzionalità implementate e i limiti attuali.

## Tecnologie utilizzate

- **Frontend:** HTML, CSS, Bootstrap, JavaScript, TypeScript, React e Vite.
- **Backend:** Node.js, Express, Python, FastAPI, PHP, Laravel, Blade, Java, Spring Boot, Spring Security e Spring Data JPA.
- **Database e accesso ai dati:** SQL, PostgreSQL, MySQL, SQLite e SQLAlchemy.
- **Strumenti:** Git, GitHub, npm, Composer, Maven, Gradle e Docker.
